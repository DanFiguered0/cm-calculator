CM Calculator

Como usar:
1. Abra index.html para testar localmente.
2. Para compartilhar com a turma, publique a pasta inteira em um serviço de hospedagem estática (GitHub Pages, Netlify ou Cloudflare Pages).
3. Compartilhe o link gerado.
4. No iPhone: Safari > Compartilhar > Adicionar à Tela de Início.

Observação: o botão Compartilhar usa o recurso nativo do celular quando disponível.
